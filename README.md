# Pokémon Emerald

This is a PC port of Pokémon Emerald based on the [pret decompilation](https://github.com/pret/pokeemerald). It builds portable executables for Linux and Windows; it does not build GBA ROMs.


Supported platforms: Linux (SDL2) and Windows (MinGW with SDL2, built from Linux or WSL).


To set up the repository, see [INSTALL_PC.md](INSTALL_PC.md).
